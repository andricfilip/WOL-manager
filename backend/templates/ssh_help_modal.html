SSH Setup - Omogućavanje Daljinskog Gašenja

Linux (Ubuntu/Debian)

1. Instalacija OpenSSH Servera

sudo apt update
sudo apt install openssh-server -y
sudo systemctl enable ssh
sudo systemctl start ssh

2. Provera Statusa

sudo systemctl status ssh

Trebalo bi da vidite "active (running)".

3. Kreiranje SSH Korisnika (Preporučeno)

sudo adduser wol-manager
sudo usermod -aG sudo wol-manager

4. Omogućavanje Shutdown Bez Lozinke

sudo visudo

Dodaj na kraj fajla:

wol-manager ALL=(ALL) NOPASSWD: /sbin/shutdown, /sbin/poweroff

5. Testiranje

ssh wol-manager@localhost
sudo shutdown -h now  # Trebalo bi da radi bez lozinke
Unos u WOL Manager:
  • SSH Host: IP adresa računara (npr. 192.168.1.100)
  • SSH Port: 22
  • SSH Username: wol-manager
  • SSH Password: lozinka korisnika

Windows 10/11

1. Instalacija OpenSSH Servera

Otvori PowerShell kao Administrator:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0

2. Pokretanje SSH Servisa

Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

3. Firewall Pravilo

New-NetFirewallRule -Name sshd -DisplayName 'OpenSSH Server (sshd)' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22

4. Kreiranje PowerShell Shutdown Skripta

Kreiraj fajl C:\Scripts\shutdown.ps1:

Stop-Computer -Force

5. Testiranje

ssh username@localhost
powershell -File C:\Scripts\shutdown.ps1
Unos u WOL Manager:
  • SSH Host: IP adresa računara
  • SSH Port: 22
  • SSH Username: Windows korisničko ime (Administrator preporučen)
  • SSH Password: Windows lozinka
Napomena: Windows zahteva Administrator privilegije za shutdown. Koristite administrator nalog ili kreirajte custom PowerShell skriptu.
Bezbednost:
  • Lozinke se čuvaju enkriptovano u bazi podataka (AES-256)
  • Preporučuje se korišćenje jakih lozinki
  • Opcionalno: Možete koristiti SSH key umesto lozinke
  • Ograničite SSH pristup samo na potrebne korisnike
